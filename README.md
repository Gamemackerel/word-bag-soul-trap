# Word Bag Soul Trap

A computer art piece: a physics simulator populated by letters that flock and swarm, occasionally assembling into words generated by an on-device language model perpetually.

## Technical Stack

- **p5.js** — canvas rendering and physics loop
- **WebLLM / MLC** — in-browser LLM inference over WebGPU (no server required)
- **Quadtree** — spatial partitioning for boid neighbor queries
- **Vite** — build tooling

## Running Locally

```bash
npm install
npm run dev
```

WebGPU is required. The model downloads and runs entirely in the browser — no Ollama, no backend.

## Controls

| Input | Action |
|---|---|
| Hold `Space` | Disable cohesion |
| `S` | Save current frame as SVG |

## Configuration

Physics, boid parameters, word lifetime, LLM settings, and letter distribution are all in [src/config.js](src/config.js).

Prompts are loaded from [prompts.txt](prompts.txt) — one prompt per line (separated by `|`), cycled automatically.

## Deploying to Personal-Webpage

Built files are committed directly into `Personal-Webpage/word-bag-soul-trap/` (not a submodule). To deploy:

```bash
# 1. Build
npm run build

# 2. Copy built files into Personal-Webpage
DEST=/path/to/Personal-Webpage/word-bag-soul-trap
cp dist/assets/* $DEST/assets/
cp dist/index.html $DEST/index.html

# 3. Fix the asset path in the copied index.html —
#    Vite writes an absolute path like /word-bag-soul-trap/dist/assets/index-HASH.js
#    Change it to a relative path: ./assets/index-HASH.js
sed -i '' 's|src="/word-bag-soul-trap/dist/assets/|src="./assets/|' $DEST/index.html

# 4. Copy prompts if they changed
cp prompts.txt $DEST/prompts.txt

# 5. Commit and push Personal-Webpage
cd $DEST/..
git add word-bag-soul-trap/
git commit -m "Rebuild word-bag"
git push origin master
```

The root `index.html` is for dev (`npm run dev`) only and is never modified by builds.
