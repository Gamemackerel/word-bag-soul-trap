# Word Bag Soul Trap

A computer art piece: a physics simulator populated by letters that flock and swarm, occasionally assembling into words generated by an on-device language model perpetually.

## Technical Stack

- **p5.js** — canvas rendering and physics loop
- **WebLLM / MLC** — in-browser LLM inference over WebGPU (no server required)
- **Quadtree** — spatial partitioning for boid neighbor queries
- **Vite** — build tooling

## Running Locally

```bash
npm install
npm run dev
```

WebGPU is required. The model downloads and runs entirely in the browser — no Ollama, no backend.

## Controls

| Input | Action |
|---|---|
| Hold `Space` | Disable cohesion |
| `S` | Save current frame as SVG |

## Configuration

Physics, boid parameters, word lifetime, LLM settings, and letter distribution are all in [src/config.js](src/config.js).

Prompts are loaded from [prompts.txt](prompts.txt) — one prompt per line (separated by `|`), cycled automatically.
